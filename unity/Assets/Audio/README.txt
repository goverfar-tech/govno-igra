Сюда кладём музыку для MusicManager (Поток Б):

  day1.mp3 / day2.wav   — дневные треки
  night1.mp3            — ночные треки

Правила:
- Имена начинаются с "day" или "night", формат mp3 или wav.
- Из нескольких файлов одной стороны суток выбирается случайный на старте.
- Для бесшовной петли лучше WAV (у mp3 на стыке бывает зазор кодека).
- Файлы подхватываются при старте Play — после добавления перезапусти.
- Для сборок папку перенесём в StreamingAssets (пока играем в редакторе).
