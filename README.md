# говно игра (survival)

Одиночная 3D FPS survival-игра. **Переехали с Godot на Unity 6** —
план разработки, карта портирования и статус: [MEMORY.md](MEMORY.md)

- `unity/` — актуальный проект (Unity 6 LTS)
- `scenes/`, `scripts/`, `resources/`, `project.godot` — старый
  Godot-прототип, оставлен как эталон логики до конца миграции

## Бюджет диска

Лимит 60–70 ГБ **не будет даже близко достигнут**, если не ставить
лишние модули. Раскладка по месту:

- Редактор Unity 6 + Windows Build Support: **~7–9 ГБ** (все остальные
  платформы — НЕ ставить: один Android + NDK это +15 ГБ впустую)
- Visual Studio Community: ~4–8 ГБ (можно пропустить, если есть VS Code)
- Проект со всеми моделями, кэшем Library и сборками: **~2–5 ГБ**
- Кэш загрузок Unity Hub: пару ГБ, чистится (Hub → шестерёнка →
  Downloads → Clear)

Итого реально: **10–20 ГБ**. Если место на C: впритык — при установке
Hub укажи другой диск для редактора (Hub → Settings → Installs location).

## Что делать после установки Unity

### 1. Установка редактора и лицензия
1. Открой **Unity Hub** → войди в аккаунт (бесплатный) — Hub сам
   активирует **Personal-лицензию**
2. **Installs → Install Editor** → ветка **Unity 6 LTS (6000.0.x)**
3. На экране модулей отметь ТОЛЬКО:
   - **Windows Build Support (IL2CPP)** — чтобы собирать .exe
   - **Visual Studio Community** — только если нет другого редактора кода
   - Всё остальное (Android, iOS, WebGL, Linux, Mac, документация) — выкл.

### 2. Открыть проект
4. **Add → Add project from disk** → папка `unity/` этого репозитория
5. Если Hub предупредит, что точной версии из ProjectVersion.txt
   нет — выбери установленную 6000.0.x, проект сам переключится
6. Первый запуск: нужен интернет — подтянется пакет **glTFast** и
   импортируются GLB-модели из `Assets/Models` (займёт несколько минут)
7. Проверь: окно **Console** без красных ошибок; в `Assets/Models`
   перетащи любое дерево в сцену — модель видна с текстурами

### 3. Собрать сцену Main (этап M1 — подробности в MEMORY.md §5/§7)
8. **File → New Scene** → сохрани как `Assets/Scenes/Main.unity`
9. **Земля**: GameObject → 3D Object → Plane, Scale = (20, 1, 20)
10. **Солнце**: на Directional Light повесь компонент **DayNight**,
    перетащи сам источник в поле Sun
11. **Игрок**: GameObject → 3D Object → Capsule, назови `Player`,
    добавь компонент **Player** (Inventory и Stats подтянутся сами).
    Создай дочерний объект `Head` в позиции (0, 1.7, 0), перенеси на
    него камеру (дефолтную Main Camera из сцены удали), в компоненте
    Player укажи поле **Head**
12. **Отладочный HUD**: на любом объекте (например, на камере)
    добавь **DebugHud**, укажи поле Stats со игрока — покажет
    HP/еду/воду, подсказки, тосты и экран смерти без настройки UI
13. **Дерево**: перетащи GLB дерева в сцену → добавь **ResourceNode**
    (+ Capsule/Box Collider, если модель без коллайдера)
14. **Предметы**: в окне Project ПКМ → **Create → Survival → Item** →
    создай `wood`, `stone`, `berry` (berry: Food Restore = 15).
    У дерева в ResourceNode укажи Yield = wood
15. **Play**: WASD/мышь/прыжок/присед, подойди к дереву — подсказка,
    E ×3 → дерево в инвентарь, выбери слот ягоды (1–5) → ЛКМ съесть,
    статы тикают. Смерть → экран смерти, R — рестарт

### 4. Когда всё работает
16. Скажи мне — двигаемся по этапу M2 (полный набор ItemData-ассетов и
    баланс против Godot-версии), затем M3 (настоящий HUD на uGUI)

## Сборка .exe

**File → Build Profiles → Windows → Build**, результат в `unity/Builds/`
(в Git не коммитится). Другу нужна вся папка сборки, не только .exe.

## Управление в прототипе

- WASD — движение, Shift — бег, Пробел — прыжок, Ctrl — присед
- Мышь — камера, E — взаимодействие, ЛКМ — съесть/выпить активный предмет
- 1–5 / колёсико — слот хотбара, R — рестарт после смерти
